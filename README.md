
1. What challenges did you face when refactoring your code to use Bootstrap?
 At first, I found it very difficult to find the right Bootstrap classes in the documentation and understand where to add them in my HTML. I also closed the card’s </div> tag too early, so the image and text appeared outside the white card. Fixing that helped me understand why the placement of the tags matters.

2. How did Bootstrap utility classes and components simplify your styling process?
 Once I understood where the classes go, Bootstrap made styling easier. I could use classes like p-3 for padding and text-center to center the text instead of writing those rules in my CSS. I also used the grid to center the card and adjust its width.

3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?
 I would use custom CSS when I need specific colors, fonts, sizes, or effects that Bootstrap’s default classes do not provide. This would give me more control when matching the original design. I did not use Tailwind for this assignment because I was unsure whether Paul would approve it. Bootstrap became easier with practice, but finding the right classes was challenging at the beginning.
